# スマホで使えるようにする・入口のオレンジを控えめに

## いただいた要望

- 「ログイン画面でオレンジが強すぎる。オレンジは控えめでよく、ラーメンなどの画像もいらない」
- 「スマホ版でできるようにしたい」

## 入口（ログイン・合言葉）

- オレンジのグラデーションと料理の画像をやめ、あたたかい地（cream）に、食堂のマーク・見出し・入力・ボタンだけを置く。
- オレンジは食堂のマークとメインのボタンだけ。ボタンのオレンジの影もやめる。
- メニュー上部の帯も、オレンジの面をやめて白いカードに（あいさつ・ご利用方法）。

## スマホで使う

1. **PayPay から別のブラウザに戻っても注文できる**
   - スマホでは PayPay アプリで支払ったあと「ふだんのブラウザ」に戻る。注文を始めたブラウザ（やホーム画面のアプリ）と違うと、
     カートが見えず、支払ったのに注文が登録されなかった。
   - PayPay へ移る前に、注文の中身を `orders/pending-{支払いID}`（status: awaiting_payment）に預ける。
     戻った先では、預けた中身を優先して注文を作り、作ったら消す。厨房ボードや「前に◯件」には出ない（status が paid / preparing ではない）。
   - 注文を始めた画面では、支払い中の ID（localStorage・3 時間で捨てる）の注文ができたら、カートを空にして注文番号へ進む
     （PendingPaymentWatcher。画面に戻ってきたときにも確かめる）。
   - PayPay の画面から「戻る」で戻ったとき、支払いボタンが「処理中…」のまま止まらないようにする。
2. **ホーム画面に追加**
   - ご利用方法を選ぶ画面に案内。iPhone・iPad は共有ボタンからの手順、Android の Chrome などはボタン（beforeinstallprompt）。
   - ホーム画面から開いているとき・パソコン・閉じたあとは出さない。iPhone 用の meta（名前「学食オーダー」）を追加。
3. **パソコンで開いたときは QR コード**
   - 広い画面（lg 以上）で左に「スマホで開く」と QR コード（https://gakushoku-order.vercel.app/）。厨房ボードには出さない。
4. **小さいスマホでも崩れない**
   - 320 / 360 / 375 / 390px 幅で全画面を確認。厨房の売り切れ一覧が 320px で横にはみ出していたのを直した
     （長い商品名を省略できるよう、グリッドの列を minmax(0, 1fr) に）。
   - 縦が短い画面では、商品シートの画像を小さくする。

## 確認方法

- 単体テスト: 預けた中身の保存・取り出し・削除、支払い中 ID の期限、ホーム画面に追加の案内の出し分け
- 画面のテスト: 戻った先のカートが空でも預けた中身で注文、注文を始めた画面のカートを空にして注文番号へ、案内の表示と閉じる
- 320 / 360 / 375 / 390px（iPhone の UA）と 1280px で全画面のスクリーンショット、横はみ出しの自動チェック
