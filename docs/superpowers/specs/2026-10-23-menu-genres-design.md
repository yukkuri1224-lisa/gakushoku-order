# メニューの拡充とジャンル分け

## 目的

食堂の掲示（「Basic MENU」「軽食メニュー」）にある商品をすべて注文できるようにし、
商品が増えても探しやすいようにジャンルで分ける。

## メニュー（23 品）

| ジャンル | 商品 | 選択肢 |
| --- | --- | --- |
| 定食 | ランチA 510・ランチB 530・ランチC 560・夕定食 490 | ランチは大盛り +150（夕定食は大盛りなし） |
| 麺類 | ラーメン 430（日替わりで味が変わる）・ワンタンラーメン 430・かけ 340・わかめ 390・たぬき 390・きつね 420・カレー 450（うどん・そば） | 大盛り +150。うどん・そばは毎回「うどん／そば」を選ぶ |
| カレー | カレーライス 480・カツカレー 580・唐揚カレー 580 | 大盛り +150・福神漬け つける／つけない |
| 軽食 | たこ焼き 270・ハムカツ 150・焼きそば 270・若鶏の香り揚げ 230・から揚げ 180・まんぞくコロッケ 150・コロッケ 80・ハッシュドポテト 150・フライドポテト 180 | なし（「1こ」の商品は価格の後ろに「/ 1こ」） |

- 掲示の大盛り価格は、どれも基本価格 +150 円。
- ランチA〜C・夕定食の中身は掲示にないため、説明は書かない（推測で書かない）。

## 参考にしたもの（note のラフデザイン）

- 商品選択画面の上に「すべて／ドリンク／フード…」のタブで絞り込み → 「すべて／定食／麺類／カレー／軽食」の丸いボタンにした。選んでいるものは墨色で塗る。スクロールしてもヘッダーの下に残す。
- 商品詳細の「カスタマイズ」（サイズ・ホット／アイス）→ うどん／そばを、サイズと同じ 2 列の選択カードにした。

## 画面

- 一覧の行は「文字が左・画像が右」。画像のない商品は文字だけの行にする（空の四角や仮のアイコンを並べない）。
- カートに入っている数は商品名の前の丸い数字で示す。
- ジャンルを切り替えたとき、一覧の先頭が絞り込みの帯に隠れていたら先頭まで戻す。
- 画像はいただいたイラスト（ラーメン・ワンタンラーメン・わかめ・たぬき・唐揚カレー）と、いらすとやのイラスト（ほかの商品）。以前の写真（ラーメン・カレー）は、イラストとの見た目をそろえるために外した。

## うどん／そば（初期値のない選択肢）

- `OptionGroup.defaultChoiceId` を省けるようにした。省いたグループは最初は未選択。
- 未選択のあいだ、商品シートのボタンは押せず「麺を選んでください」と出す。
- 注文の選択肢には `mustChoose: true` を付ける（それ以外の選択肢には項目ごと付けない。Firestore は `undefined` を拒否するため）。
- 厨房では、うどん／そばは毎回出す（普通の枠）。大盛りは黄色、福神漬けなしは赤のまま。

## 確認方法

- 単体テスト: メニューのデータ（ジャンル・件数・id の重なり・大盛り価格・うどん／そば・画像ファイルの有無）、未選択の検出、`mustChoose`
- 画面のテスト: ジャンルの絞り込み、麺を選ぶまでカートに入れられない、厨房にそばが出る
- `npm run build`、390px 幅でモック決済の一連の流れ（絞り込み → たぬき（そば・大盛り）→ から揚げ 3 こ → カツカレー（福神漬けなし）→ 厨房）
